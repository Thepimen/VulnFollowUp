    API->>Val: Verify JWT Role (ADMIN/ANALYST) & Validate CVSS v3.1/v4.0 Prefix/Score/Severity
    Val-->>API: Validated Payload
    API->>DB: BEGIN TRANSACTION: Insert into vulnerabilities + vulnerability_assets (N:M) + audit_logs
    DB-->>API: COMMIT (Linked to Assets & ICT Providers under EU DORA)
    API-->>User: 201 Created (Vulnerability DTO)

    Note over User,DB: Flow B — State Machine Transition (ABIERTA → PENDIENTE DE REMEDIACIÓN → RESUELTA → CERRADA)
    User->>API: PATCH /api/v1/vulnerabilities/{id}/status (newStatus, justification)
    API->>Val: Check Transition Rules (Only ADMIN can set CERRADA)
    API->>DB: UPDATE vulnerabilities SET status = newStatus + INSERT INTO audit_logs
    DB-->>API: COMMIT
    API-->>User: 200 OK

    Note over User,Room: Flow C — Paginated Green Software Query & Android Offline Sync
    User->>API: GET /api/v1/vulnerabilities?page=0&size=20&severity=CRITICAL

    DB-->>API: Paginated Slice
    API-->>User: 200 OK (Page<VulnerabilitySummaryDTO>)
    User->>Room: Upsert Page into Local SQLite Room Cache for Offline Consultation

    Note over User,Conc: Flow D — PSP Concurrent Batch Ingestion & ProcessBuilder Report Export

    API->>Conc: Submit Async Task (ExecutorService) & Spawn OS Process (ProcessBuilder)
    Conc-->>API: Generated Executive DORA & CVSS Report File
